# 2048 Ninjas

A ninja-themed take on the 2048 puzzle, built with Next.js (App Router), React 19 and Tailwind v4.
Slide tiles to combine matching ninjas and work your way up from a humble Rookie to the Sensei —
and beyond, all the way to the Immortal.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:2048.

## Visual design

Ninja Festival brings a pastel floating-island entrance, glossy character tiles, chunky controls, and a winding adventure map through three colorful worlds. Earn stars across nine missions, unlock scenery, and celebrate with combo bursts and animated medals. Phones show a compact next-recruit recipe above the board. The original Shadow Dojo and other themes remain available in Settings; saved runs, progress, sound controls, and reduced-motion preferences carry over.

## Sound design

The dojo uses procedural Web Audio: filtered wind for movement, wooden strikes and pentatonic plucks for merges, rising combo notes, smoke bursts, undo sweeps, and layered bells for rank and chapter unlocks. Settings includes a saved volume slider, immediate mute, and a sound preview. Audio starts only after a player gesture.

## Features

- **Dashboard** hub: pick Classic (any size), Coach, Daily, Timed, Race or Puzzles, with your progress on each card.
- **17 original ninjas** drawn as inline SVG — no image assets.
- **Modes:** Classic, Daily challenge (same seeded board for everyone each day), Timed (60 seconds),
  and **Race** — two players on identical boards (arrows vs WASD), first to the target ninja wins.
- **Board sizes:** 3×3, 4×4, 5×5, 6×6, each with its own best score.
- **Smoke Bomb tile:** a rare wildcard that merges with anything (optional, never in Daily).
- **Limited undos:** 3 per game by default, or unlimited from Settings.
- **Progression:** stats, ninja collection with unlock dates, local top-10 leaderboard.
- **Global leaderboard:** submit finished games under a nickname; boards per mode/size plus a daily board.
- **AI:** a Hint button (expectimax search) and a "Watch AI" autoplay mode. AI-assisted games stay off the global board.
- **Coach:** the AI reviews every move you make (great / good / okay / risky / blunder), explains why, shows the better
  move, and gives standing advice about your board plus a strategy playbook.
- **Puzzles:** 12 preset boards with a goal ninja and a move limit, generated by AI play and verified solvable by search;
  earn up to three stars per puzzle.
- **87 achievements** across nine categories (ninjas, scores, skill, modes, board sizes, smoke bombs, puzzles, habits, secret).
- **Progression loop:** XP and ninja levels (Rookie → Legend), three seeded daily missions, a weekly challenge with a
  rotating rule set, daily streak with earnable streak freezes, and unlockable board skins (Lacquer, Bamboo, Gold).
- **Session feel:** personal-best celebration, combo counter with rising pitch, shake on 512+ merges, danger wobble on a
  full board, near-miss framing and a Coach summary on game over.
- **Share:** PNG share card of your final board, and "beat my score" links for the daily challenge.
- **Feel:** score pop-ups, synthesized sound effects, haptics on phones, confetti on the win, squash/nudge animations,
  "new ninja" and achievement toasts.
- **Themes:** Ninja Festival, Shadow Dojo, System, Mountain Dojo, Midnight Dojo, Bamboo Grove.
- **Share** your score via the native share sheet or clipboard.
- **Accessible:** screen-reader move announcements, keyboard-only play, reduced-motion support.
- **PWA:** installable with offline support (service worker registers in production builds).

Progress is stored in the browser's localStorage. The original storage keys and achievement IDs are retained so saves from the previous theme still work. The global leaderboard is the only server feature.

## Global leaderboard storage

`/api/leaderboard` stores scores in one of two places:

- **Upstash Redis** (recommended for deployment) — copy `.env.example` to `.env.local` and fill in
  `UPSTASH_REDIS_REST_URL` and `UPSTASH_REDIS_REST_TOKEN` from a free Upstash database.
- **Local JSON file** (`.data/leaderboard.json`, gitignored) — used automatically when the env vars are
  missing. Fine for playing locally; on serverless hosts the file won't persist, so use Upstash there.

Submissions are validated (name length, plausible score for the top tile, mode/size ranges) and lightly
rate-limited per IP.

## Playing on a phone

1. Start the server on your computer: `npm run dev` (or `npm run build && npm start`).
2. Run `npm run phone` — it prints the address to open and a QR code you can scan.
3. On the phone (same Wi-Fi), open that address. The board is swipe-controlled; Race mode has one swipeable board per player.
4. For full-screen offline play, tap **Install** (Android) or **Share → Add to Home Screen** (iPhone). A production
   build (`npm start`) registers the offline service worker; the dev server doesn't.

To play from anywhere, deploy it (e.g. Vercel) and add the two Upstash keys for the global leaderboard.

## Controls

- Arrow keys, `WASD` or `HJKL` to move (in Race: arrows = Player 1, WASD = Player 2)
- Swipe on touch devices
- `U` / `Z` – undo
- `R` – new game
- `Esc` – close a panel

## Project layout

- `src/lib/game.ts` – pure game engine (move, merge, spawn, smoke bombs, timed clock, undo accounting). No React.
- `src/lib/rng.ts` – seedable PRNG used for deterministic daily boards.
- `src/lib/ninjas.ts` – the ninja ladder (2 → 131072) with colours, art kind and descriptions.
- `src/lib/progress.ts` – stats, collection, achievements and leaderboard logic.
- `src/lib/ai.ts` – expectimax AI used for hints, autoplay and the Coach.
- `src/lib/coach.ts` – move review and strategy advice.
- `src/lib/engagement.ts` – XP/levels, daily missions, weekly challenge, skins, near-miss framing.
- `src/lib/shareCard.ts` – canvas renderer for the share image.
- `src/lib/puzzles.ts`, `src/lib/puzzleData.ts` – puzzle definitions (generated; see the script note below).
- `src/lib/online.ts`, `src/app/api/leaderboard/route.ts`, `src/lib/server/leaderboardStore.ts` – global leaderboard client, API and storage adapter.
- `src/lib/settings.ts`, `src/lib/sound.ts`, `src/lib/storage.ts` – settings/themes, Web Audio effects, safe localStorage.
- `src/components/NinjaIcon.tsx` – original SVG illustrations for every ninja.
- `src/components/Game.tsx` – client orchestrator: input, modes, persistence, toasts, share, AI, submission.
- `src/components/Race.tsx` – two-player race view.
- `src/components/Dashboard.tsx` – the home screen.
- `src/components/panels/` – Stats, Collection, Achievements, Leaderboard, Settings, Ninja detail.
- `src/app/manifest.ts`, `public/sw.js` – PWA manifest and service worker.

## Regenerating puzzles

`src/lib/puzzleData.ts` was produced by letting the AI play seeded games, snapshotting mid-game boards, and running a
breadth-first search over all move sequences to find the fewest moves to the next ninja (`par`). Any board with a
2–6 move solution is kept. The PRNG state is stored so the tiles that spawn are identical on every attempt.
